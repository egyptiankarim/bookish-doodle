## `bookish-doodle`

This repository is where I intentionally track consumption of books, music, film, etc. The name `bookish-doodle` is a bit of serendipity; GitHub randomly generated the suggestion when I created the repository, and I thought it fit the vibe.

### Repository conventions

To help structure the content in here, I'm trying to stick to the following high-level conventions:

- Projects for each special initiative, course, etc (with standard "To do", "Doing", "Done" swim lanes).
- Directories with their own READMEs for special initiatives, course content (when necessary), etc.
- Issues for reading assignments and specific "go do" type things.
- When the principal topic is reading material, we'll use an inline citation format for Issue titles, with a full citation in the Issue body. I'll wing it otherwise but try to keep things meaningful at a glance.
- Issue threads for open discussion, brainstorming, note taking, etc.
